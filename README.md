# Portfolio

Mon portfolio personnel, réalisé en React avec Vite. Il présente mon parcours, mes compétences et mes projets, en français et en anglais, et permet de télécharger mon CV.

## Fonctionnalités

- Site bilingue français / anglais, avec tous les textes rangés dans des fichiers JSON
- Liste de projets qui défile à l'horizontale en boucle infinie, à la molette ou au doigt
- Description de chaque projet et lien vers son code au survol de l'image
- Carte d'information au survol de chaque compétence
- Téléchargement du CV dans la langue choisie

## Technologies

- **React**
- **Vite** pour le serveur de développement et le build
- **Radix UI** pour la carte au survol, le séparateur et la barre de progression

## Prérequis

- **Node.js 20.19+ ou 22.12+** (exigé par Vite)
- `npm` (fourni avec Node.js)

## Installation

À la racine du projet :

```sh
npm install
npm run dev
```

Le site est ensuite accessible sur `http://localhost:5173`.
